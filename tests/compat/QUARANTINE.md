# Quarantined Compatibility Tests

This document tracks compatibility tests tagged with `#[ignore = "flaky: <reason>"]`.

Flaky compatibility tests should be quarantined so they do not cause false positives or block CI runs in `compat-baseline`. Quarantined tests are run in a separate non-blocking `compat-quarantine` job in CI.
